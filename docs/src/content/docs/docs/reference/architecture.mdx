## Vue d'ensemble

```
Navigateur (React)
  ├─ POST /v1/chat/completions ─► serveur Bun ─► LLM (API compatible OpenAI)
  ├─ POST /api/check ───────────► serveur Bun : correcteur grammatical (worker)
  └─ POST /api/analyze ─────────► serveur Bun : diff, croisement, journal SQLite
```

Le serveur Bun sert aussi les fichiers statiques de l'interface (`dist/`).

| `journal.progress.ts` | Lecture du journal pour l'écran Progression (requêtes en lecture seule) |

| `telemetry.ts` | Initialisation d'OpenTelemetry |
| `src/analysis/diff.ts` | Diff au niveau du mot |
| `src/analysis/fiches.ts` | Fiches de règles et détection des confusions |
| `src/analysis/analyze.ts` | Croisement du diff et de LanguageTool |
| `src/analysis/score.ts` | Note sur 20 |
| `src/analysis/regles/seuils.ts` | Seuils du cycle de vie des règles |

| `src/analysis/progression/reglages.ts` | Réglages de l'écran Progression (score de maîtrise, fenêtres, minimums) |

## Choix de conception

- **Le code d'analyse est partagé.** `src/analysis` ne dépend ni du navigateur ni de Bun ; il est exécuté par le serveur et testé sous Vitest.
- **L'analyse ne bloque jamais la correction.** Si le correcteur grammatical ou le journal échoue, le texte corrigé reste affiché et copiable.
- **Une clé stable par règle.** Les confusions des fiches ont une clé interne (`PAIRE:on/ont`) ; les autres fautes utilisent l'identifiant de règle de LanguageTool. C'est ce qui permet de compter les récurrences.
- **Un correcteur grammatical intégré.** Les règles françaises de LanguageTool tournent dans le serveur Bun grâce à [`@valueerror/ltjs-core`](https://github.com/valueerrorx/languagetool-js) et `@valueerror/ltjs-lang-fr`, portage JavaScript de LanguageTool distribué sous licence GPL-3.0-or-later. Elles s'exécutent dans un worker pour ne pas bloquer le serveur, se chargent en arrière-plan au démarrage (quelques secondes) et occupent environ 1 Go de mémoire vive.
- **Mono-utilisateur.** Il n'y a pas d'authentification. Les tables portent une colonne `user_id` pour ne pas fermer la porte au multi-utilisateur.
