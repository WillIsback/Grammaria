## Mes textes sont-ils envoyés quelque part ?

Ils sont envoyés au modèle que vous avez configuré dans `LLM_TARGET` et à votre instance LanguageTool. Avec un modèle local, rien ne quitte votre réseau. Le journal ne conserve que les phrases contenant une faute.

## Le bandeau « LanguageTool n'est pas disponible » s'affiche

Vérifiez que le conteneur tourne :

```bash
curl -s http://localhost:3002/v2/languages
```

Sans LanguageTool, la correction fonctionne mais seules les confusions des fiches sont classées.

## La correction échoue ou ne démarre pas

Vérifiez que le serveur du modèle répond :

```bash
curl -s http://localhost:25000/v1/models
```

Une erreur 502 signifie que Grammaria ne joint pas `LLM_TARGET`.

## Le modèle répond à mon texte au lieu de le corriger

Le prompt l'interdit, mais un petit modèle peut ne pas respecter la consigne. Essayez un modèle plus capable.

## Le modèle renvoie une réponse vide ou du texte de réflexion

Certains modèles produisent un bloc de réflexion avant leur réponse. Laissez `LLM_DISABLE_THINKING=true` pour vLLM et Qwen ; mettez `false` pour les fournisseurs qui rejettent ce paramètre.

## Pourquoi une correction est-elle « Non classé » ?

Le modèle a modifié un passage que ni les fiches ni LanguageTool n'expliquent. C'est le plus souvent une reformulation de style. Elle n'entre pas dans la note.

## Ma note est très basse sur un message court

C'est attendu : une faute dans dix mots représente une densité élevée. Fiez-vous à la moyenne sur sept jours, qui pondère par le nombre de mots.

## Le journal a disparu après une mise à jour du conteneur

Le fichier SQLite doit être sur un volume. Voir [Déploiement Docker](/docs/exploiter/docker/).

## Peut-on avoir plusieurs utilisateurs ?

Non. Grammaria est conçu pour une personne et n'a pas d'authentification.
