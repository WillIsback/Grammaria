## Mes textes sont-ils envoyés quelque part ?

Ils sont envoyés uniquement au modèle que vous avez configuré dans `LLM_TARGET` : l'analyse grammaticale tourne dans le serveur Grammaria. Avec un modèle local, rien ne quitte votre réseau. Le journal ne conserve que les phrases contenant une faute.

## Le message « Le correcteur grammatical est indisponible » s'affiche

Le correcteur grammatical intégré n'a pas pu analyser le texte. Consultez les journaux du serveur (lignes `[Grammar]`) et vérifiez que le serveur dispose d'environ 1 Go de mémoire vive libre pour charger les règles. Vous pouvez aussi l'interroger directement :

```bash
curl -s -X POST http://localhost:25000/api/check -H "Content-Type: application/json" -d '{"text":"Ils on vu le film."}'
```

Sans correcteur grammatical, la correction fonctionne mais seules les confusions des fiches et les accords sont classés.

## La correction échoue ou ne démarre pas

Vérifiez que le serveur du modèle répond :

```bash
curl -s http://localhost:25000/v1/models
```

Une erreur 502 signifie que Grammaria ne joint pas `LLM_TARGET`. Le message affiché sous le texte en donne la cause : serveur injoignable, requête refusée (clé d'API manquante ou invalide), ou aucun modèle détecté, auquel cas renseignez `LLM_MODEL_NAME`.

## Le modèle répond à mon texte au lieu de le corriger

Le prompt l'interdit, mais un petit modèle peut ne pas respecter la consigne. Essayez un modèle plus capable.

## Le modèle renvoie une réponse vide ou du texte de réflexion

Certains modèles produisent un bloc de réflexion avant leur réponse. Laissez `LLM_DISABLE_THINKING=true` pour vLLM et Qwen ; mettez `false` pour les fournisseurs qui rejettent ce paramètre.

## Pourquoi une correction est-elle « Non classé » ?

Le modèle a modifié un passage que ni les fiches, ni la détection des accords, ni les règles de LanguageTool n'expliquent. C'est le plus souvent une reformulation de style. Elle n'entre pas dans la note.

## Ma note est très basse sur un message court

C'est attendu : une faute dans dix mots représente une densité élevée. Fiez-vous à la moyenne sur sept jours, qui pondère par le nombre de mots.

## Le journal a disparu après une mise à jour du conteneur

Le fichier SQLite doit être sur un volume. Voir [Déploiement Docker](/docs/exploiter/docker/).

## Peut-on avoir plusieurs utilisateurs ?

Non. Grammaria est conçu pour une personne et n'a pas d'authentification.
