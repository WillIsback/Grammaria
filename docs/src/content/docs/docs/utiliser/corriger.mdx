## En pratique

1. Collez votre texte dans la zone de gauche.
2. Cliquez sur **Corriger**.
3. Le texte corrigé s'affiche à droite au fil de la génération.
4. Cliquez sur **Copier**. Vous n'avez pas à attendre la fin de l'analyse des fautes.

Sur un écran large (768 px et plus), le bouton **Corriger** est dans l'en-tête du panneau « Texte à corriger », et les boutons **Copier** et **Réinitialiser** dans celui du panneau « Résultat corrigé », au-dessus des zones de texte. Sur mobile, ils restent sous les zones de texte.

Un texte est limité à 10 000 caractères. Au-delà, il est coupé à la fin du dernier mot complet et un message indique combien de caractères ont été corrigés : la suite n'est ni corrigée, ni copiée, ni comptée dans la note.

Les caractères typographiques sont conservés tels quels : apostrophe courbe (’), guillemets, points de suspension, tirets, €, œ, espaces insécables, lettres d'autres langues dans les noms propres.

## Mode de correction

Le mode indique au modèle le registre à respecter.

| Mode | Registre |
|---|---|
| Formel | formel et professionnel |
| Semi-formel | neutre, adapté au courrier |
| Informel | décontracté, conversationnel |
| Technique | texte technique, clarté et précision |

## Types de corrections

Quatre cases activent ou désactivent ce que le modèle a le droit de corriger : **grammaire**, **orthographe**, **syntaxe** et **style**. Décochez « style » si vous voulez que vos tournures restent intactes.

## Modèle

Le menu **Paramètres → IA** (bouton ⚙️ de l'en-tête, à côté du thème) liste les modèles exposés par votre serveur, section **Modèle LLM**. Le premier est sélectionné par défaut. Dans l'application de bureau, la même rubrique contient aussi le **Serveur du modèle** (adresse, clé API, raisonnement).

La correction est toujours faite par le modèle. Les règles de LanguageTool servent uniquement à classer les fautes (voir [Fonctionnement](/docs/decouvrir/fonctionnement/)).

## Votre texte n'est jamais une consigne

Le modèle a pour instruction de traiter votre texte comme un contenu à corriger, pas comme une demande. Si vous collez « Peux-tu m'envoyer le fichier ? », il corrige la phrase et n'y répond pas.
