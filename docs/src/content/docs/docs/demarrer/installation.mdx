## Prérequis

- Un modèle de langage exposé par une API compatible OpenAI.
- Pour une installation depuis les sources : [Bun](https://bun.sh), Node.js `^22.18`, `^24.11` ou `>=26`, [Rust](https://rustup.rs) (1.75 au moins) et `git`, pour compiler le correcteur grammatical. Pour une installation par conteneur : Docker.
- Environ 300 Mo de mémoire vive pour le serveur et son correcteur grammatical.

## Depuis les sources

```bash
git clone https://github.com/WillIsback/Grammaria.git
```

```bash
cd Grammaria
```

```bash
cp .env.example .env
```

Renseignez au minimum `LLM_TARGET` dans `.env` (voir [Configuration](/docs/demarrer/configuration/)), puis :

```bash
npm install
```

```bash
npm run build
```

Construisez le correcteur grammatical (moteur Rust grammaria-rc, récupéré à la version prévue et compilé en moins d'une minute ; binaire et données dans `moteur/`) :

```bash
npm run build:moteur
```

```bash
bun run server.ts
```

L'application est ensuite accessible sur [http://localhost:25000](http://localhost:25000). Le correcteur grammatical (moteur grammaria-rc, avec les règles françaises de [LanguageTool](https://languagetool.org)) est lancé par le serveur : aucun service supplémentaire n'est à lancer. Ses règles se chargent en arrière-plan au démarrage, en moins d'une seconde.

## Avec Docker

Construisez l'image à partir du dépôt :

```bash
docker build -t grammaria .
```

La construction compile aussi le correcteur grammatical ; elle a besoin d'un accès à GitHub pour récupérer son code (dépôt public).

Lancez-la ensuite comme décrit dans [Déploiement Docker](/docs/exploiter/docker/).

:::note
Une image prête à l'emploi et un script `install.sh` sont publiés automatiquement à chaque version étiquetée du dépôt. Tant qu'aucune version n'est publiée, construisez l'image vous-même.
:::

## Vérifier l'installation

1. Ouvrez l'application, puis le menu **Paramètres** (bouton ⚙️ de l'en-tête) : le modèle détecté apparaît dans la rubrique **IA**, section **Modèle LLM**.
2. Collez une phrase contenant une faute et cliquez sur **Corriger**.
3. Le détail des corrections s'affiche sans le message « Le correcteur grammatical est indisponible : l'analyse des fautes est partielle. »
